# Wimzyware Product Summary

## What Is Wimzyware?

Wimzyware is a safe AI-assisted workspace for managing website and app changes, built around staging, approvals, specialized agents, and production-ready deployment flow.

**Brand:** [wimzyware.com](https://wimzyware.com)

## How It Works

1. **Client requests a change** — via the dashboard or conversation interface.
2. **AI agents propose and implement the change** — using specialist knowledge.
3. **System generates a staging preview** — so changes can be reviewed visually.
4. **Approval gate (tier-dependent)** — depending on the account tier, changes may require explicit approval before going live.
5. **Production deployment** — approved changes are deployed to production.

## Key Differentiators

### Safe Change Sandbox

An approval-aware AI pipeline. Every change flows through staging before production, with configurable approval requirements based on account tier and project type.

### Multi-Agent Workspace

Specialist agents collaborate on changes, each with domain expertise:

- **Marketing** — campaign and messaging alignment
- **Design** — visual and layout decisions
- **Copywriting** — tone, clarity, and content quality
- **Frontend Dev** — UI implementation
- **Backend Dev** — server-side logic and integrations
- **SEO** — search optimization and metadata
- **Accessibility** — WCAG compliance and inclusive design
- **QA** — testing and validation

### Project-Type Aware Controls

Different pricing, permissions, and capabilities depending on project type:

- **Static Sites** — simpler pipelines, lower cost
- **Backend Apps** — more complex pipelines, additional safeguards
