# Wimzyware Roadmap

## Phase 1 — MVP

- Landing page (static HTML/CSS/JS)
- App shell with dashboard UI
- Mock agents, conversations, and projects
- Fake staging flow rendered in UI (no real deploys)

## Phase 2 — Core Services

- Real authentication via AWS Cognito
- Connect AI services via AWS Bedrock
- Basic change request pipeline (submit, process, preview)

## Phase 3 — Staging and Approvals

- Real staging deploys to S3/CloudFront
- Approval workflows with tier-based rules
- Project-type aware permissions and controls

## Phase 4 — Multi-Agent and Billing

- Multi-agent routing (assign specialist agents per change)
- Agency features (manage multiple client projects)
- Billing integration via Stripe

## Phase 5 — Production Pipeline

- Full production deployment pipeline
- Monitoring and alerting
- Scaling and performance optimization
